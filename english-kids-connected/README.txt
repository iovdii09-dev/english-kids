ENGLISH KIDS — Supabase-підключення (учнівський доступ за кодом)

У папці три файли:
- index.html — інтерфейс сайту, класи 1–5 та демонстраційні уроки;
- auth.js — вхід учителя та анонімна реєстрація учня за кодом;
- config.js — Project URL і publishable key.

ВАЖЛИВО: ця версія підключає авторизацію, але уроки, тести, створені вчителем матеріали та прогрес поки що залишаються локальними у браузері. Вони ще не записуються в таблиці Supabase. Не запускайте для реальних учнів, доки не перевіримо запрошення та права доступу.

ПЕРЕД ПУБЛІКАЦІЄЮ:
1. Відкрийте config.js.
2. Вставте Project URL і publishable key саме з проєкту English Kids.
3. НІКОЛИ не вставляйте sb_secret_ або service_role key у файли сайту.
4. У Supabase Auth має бути ввімкнено Anonymous Sign-Ins.
5. Edge Function student-invite має бути розгорнута та перевірена.
6. У таблиці invitation_codes мають існувати активні коди класів.

ЯК ПРАЦЮЄ УЧЕНЬ:
1. На сайті вводить ім’я та код від учителя.
2. Сайт створює анонімний сеанс Supabase на цьому пристрої.
3. Сайт передає код у student-invite з токеном цього сеансу.
4. Функція активує код і призначає клас у профілі.

УЧИТЕЛЬ:
Входить за вже існуючим email і паролем. Для цього проєкту використовуйте наявний учительський обліковий запис.

ВАЖЛИВО ПРО ПРИСТРІЙ:
Анонімний учнівський сеанс зберігається в браузері на цьому пристрої. Якщо очистити дані браузера або перейти на інший пристрій, доступ може загубитися. Для спільного пристрою спочатку вийдіть з попереднього учня.

НЕ ГОТОВО ДЛЯ РЕАЛЬНИХ ДІТЕЙ ДО ПЕРЕВІРКИ:
- створення й багаторазового використання кодів;
- політик RLS для всіх таблиць;
- збереження уроків і прогресу в Supabase;
- сценарію виходу та зміни учня.
